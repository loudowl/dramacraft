# DramaCraft Design Brief

## 1. Visual Identity

### Color Palette
- **Primary Color:** Electric Purple (#8A2BE2) - Represents creativity and drama.
- **Secondary Color:** Sunset Orange (#FF4500) - Adds warmth and excitement.
- **Accent Color:** Lime Green (#32CD32) - Highlights actions and interactive elements.
- **Background Color:** Midnight Blue (#191970) - Provides a dark, immersive canvas.
- **Text Color:** Off White (#F5F5F5) - Ensures readability against darker backgrounds.

### Mood/Tone
- **Mood:** Creative, dynamic, and engaging.
- **Tone:** Modern, youthful, and slightly dramatic.

## 2. Typography

- **Heading Font:** Montserrat (Google Fonts)
  - **Sizes:** H1: 32px, H2: 28px, H3: 24px
  - **Weights:** Bold (700), Regular (400)

- **Body Font:** Open Sans (Google Fonts)
  - **Sizes:** Body: 16px, Small Text: 14px
  - **Weights:** Regular (400), Light (300)

## 3. Component Library

- **Voice Recorder:**
  - Circular button with a microphone icon, pulse animation when active.
  - Colors: Primary for active, Secondary for inactive.

- **Drama Preview Card:**
  - Thumbnail image with a play button overlay.
  - Text overlay for title and creator name.

- **Navigation Bar:**
  - Bottom navigation with icons for Home, Create, Discover, Profile.
  - Active icon highlighted with Accent Color.

- **Credit Management:**
  - Display current credits with a purchase button.
  - Modal for purchasing credits.

- **Sharing Options:**
  - Social media icons with hover effects.
  - Colors shift from Text Color to Accent Color on hover.

## 4. Key Screen Layouts

### Home Screen
- **Layout:** Vertical scroll of drama previews with swipeable cards.
- **Features:** Search bar at the top, highlight reel for trending dramas.

### Create Screen
- **Layout:** Central voice recording button, beneath a text prompt.
- **Features:** Progress bar for recording duration, tips for creating engaging content.

### Discover Screen
- **Layout:** Grid of drama thumbnails, infinite scroll.
- **Features:** Filters for genre and popularity, sort options.

### Profile Screen
- **Layout:** User stats at the top, followed by a list of created dramas.
- **Features:** Edit profile button, credit balance display.

## 5. Responsive Strategy

- **Mobile:** Up to 600px width, single-column layout, touch-friendly components.
- **Tablet:** 601px to 900px width, two-column layout for discovery and profile.
- **Desktop:** Above 900px width, three-column layout with expanded navigation and additional content panels.

## 6. Micro-interactions

- **Button Animations:** Slight scale-up on hover with a shadow effect.
- **Swipe Transitions:** Smooth horizontal swipe with a fade effect for cards.
- **Loading Indicators:** Spinning icons using Accent Color for AI processing.

## 7. Accessibility

- **WCAG Compliance:** Ensure all text has a contrast ratio of at least 4.5:1.
- **Keyboard Navigation:** All interactive elements should be accessible via keyboard.
- **Alternative Text:** Provide alt text for all images and icons.
- **Focus States:** Clear focus indicators for all navigable elements.

This design brief outlines the visual and functional elements necessary to create an engaging and accessible user experience for DramaCraft, ensuring a modern, cohesive, and inclusive design.
