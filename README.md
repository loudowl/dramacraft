# DramaCraft

DramaCraft is a mobile application that transforms 30-second user-recorded voice notes into engaging visual micro-dramas using AI technology.

## Setup Instructions

### Prerequisites

- Node.js 18.x
- PostgreSQL 14.x
- AWS account for S3 and other services
- OpenAI and ElevenLabs API keys
